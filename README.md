# MeloVerse — المشروع

منصة قراءة المانجا / المانهوا / المانها مع دعم كامل للعربية (RTL) والإنجليزية (LTR).
المصدر الأول للمحتوى: **MangaDex API الرسمي** (https://api.mangadex.org).

```
meloverse/
├── web/                  # الموقع الإلكتروني (Node.js + Express + SPA)
│   ├── server.js         # خادم يوكّل MangaDex مع تخزين مؤقت (cache)
│   └── public/           # الواجهة: index.html + styles.css + app.js
├── android/              # تطبيق أندرويد (Kotlin + Jetpack Compose)
│   └── app/src/main/java/com/meloverse/app/
│       ├── data/         # MangaDex API + النماذج + المخزن المحلي (JSON)
│       └── ui/           # الشاشات: الرئيسية، البحث، التفاصيل، القارئ، المكتبة
├── dist/                 # ملفات APK الجاهزة للتثبيت
└── tools/                # أدوات البناء (SDK + Gradle + JDK — محلية)
```

---

## 1) تشغيل الموقع الإلكتروني

```bash
cd web
npm install
node server.js
# افتح http://localhost:3000
```

المميزات الحالية:
- الرئيسية: الأكثر متابعة + آخر التحديثات (مفلترة حسب اللغة المختارة)
- البحث بالعنوان (إنجليزي/ياباني/كوري/صيني...)
- صفحة العمل: غلاف، وصف، حالة، تصنيفات، قائمة فصول
- القارئ: **عمودي (Webtoon)** مع تمرير لا نهائي بين الفصول، أو **أفقي (Paged)**
- حفظ التقدم والمفضلة محليًا (localStorage) — دون حساب
- تبديل العربية/الإنجليزية يقلب الاتجاه RTL/LTR تلقائيًا

## 2) بناء APK

```bash
export ANDROID_HOME=$PWD/tools/android-sdk
cd android
../tools/gradle-dist/gradle-8.13/bin/gradle :app:assembleRelease
# الناتج: android/app/build/outputs/apk/release/app-release.apk
```

- الحزمة: `com.meloverse.app` | minSdk 26 | targetSdk 35
- التوقيع: keystore محلي `android/keystore/meloverse.jks`
  (كلمة المرور: `meloverse2026` — غيّرها قبل أي نشر حقيقي)
- التطبيق يتصل مباشرة بـ MangaDex API (لا يحتاج سيرفرًا للقراءة)

## 3) الميزات المخططة (المراحل التالية)

- حساب مستخدم + مزامنة تقدم القراءة بين الأجهزة
- تنبيهات الفصول الجديدة (FCM)
- تحميلات مشفرة للقراءة دون اتصال
- لوحة الأدمن: محرك سحب بجدولة وكوتا يومية + إعدادات إعلانات عن بُعد
- خادم صور وسيط (ضغط WebP/AVIF)
- نظام بناء APK من اللوحة (بضغطة زر)

## ملاحظات معروفة

- بعض الأعمال المرخصة (مثل Solo Leveling) فصولها خارجية على MangaDex —
  تُصفى تلقائيًا من قائمة الفصول.
- البحث العربي بالعنوان محدود لأن MangaDex يطابق العناوين بلغتها الأصلية —
  الحل القادم: فهرس عناوين عربية محلي في السيرفر الخلفي.
- المحتوى ملك لأصحابه؛ المصدر الأساسي API رسمي عام.

## 4) التحديث الكبير: المجتمع + محرك المزامنة + النشر

### الرابط العام
الموقع منشور عبر نفق Cloudflare:
**https://ban-courier-rated-entrepreneurs.trycloudflare.com**
(رابط النفق مؤقت — يُعاد إنشاؤه عند إعادة تشغيل الخادم؛ للحصول على رابط ثابت: `cloudflared tunnel login` + نفق مسمّى)

### المجتمع: التعليقات والإشراف
- تسجيل/دخول (كلمات مرور مشفرة scrypt + رموز جلسة HMAC)
- تعليقات على **العمل** أو **الفصل** مع إبلاغ 🚩 وحذف (صاحب التعليق أو الأدمن)
- **لوحة الإشراف**: `/admin.html` — حساب مبدئي `admin / admin123` (غيّره!)
  - حذف تعليقات مسيئة، حظر/إلغاء حظر حسابات (المحظور يُرفض فورًا)
  - حجب مانجا/فصل/أنمي غير مناسب — يختفي من كل القوائم والبحث فورًا

### محرك المزامنة (Content Sync Engine)
- **فهرس محلي** (JSON store) للأعمال والفصول + **إثراء AniList** (تقييمات/أوصاف)
- محولات مصادر: **MangaDex** (رئيسي، فعّال) · **AniList** (إثراء، فعّال) · **Comick** (انتقل إلى comick.dev ومحمي بـ Cloudflare — الواجهة جاهزة وتُحاول تلقائيًا) · MangaUpdates/Consumet (واجهات معرّفة)
- **جدولة مرنة** (من لوحة الأدمن → مهام السحب):
  - السحب اليومي: 75 عملًا جديدًا (افتراضي، قابل للتعديل)
  - تتبع مستمر كل 30 دقيقة للفصول الجديدة
  - مزامنة الأكثر شهرة كل 6 ساعات + تشغيل يدوي
  - السحب الشامل (معطّل افتراضيًا — سقف أمان 500)
- **سحب فصل بالمعرف**: تخزين صفحات الفصل محليًا (تشفير لاحقًا)

### مرايا الصور
سلسلة جاهزية بالترتيب: مصدر العمل (at-home) ← فحص HEAD ← مرآة Comick.
Bato.to / MangaBuddy / MangaPill: واجهات معرّفة (ready=false) — تُفعَّل عند توفر متطلب (معظمها خلف Cloudflare).

### ملاحظات أمان
- غيّر كلمة مرور الأدمن وكلمة مرور keystore قبل أي نشر عام
- النفق المؤقت trycloudflare عام — لا تضع بيانات حساسة

## 5) التحديث الشامل: الإصلاحات + لوحة الأدمن المتكاملة + الأتمتة

### إصلاحات حرجة
- **انهيار الواجهة**: خطأ Temporal Dead Zone (استدعاء دالة قبل تهيئة متغيرها) + غياب استدعاء التوجيه الأولي — أُصلحا، الواجهة تعمل الآن من أول تحميل.
- **بطء السيرفر**: نظام طوابير مهام خلفية (2 عمال) — المهام الثقيلة (سحب/بناء) لا توقف استجابة الموقع.

### لوحة الأدمن المتكاملة (`/admin.html` — 10 تبويبات)
1. **لوحة القيادة**: إحصائيات حية (مستخدمون، تعليقات، بلاغات، فهرس)
2. **مزامنة المحتوى**: أزرار — سحب 1000 عمل شامل / سحب يومي 100 / متابعة مستمرة / الأكثر شهرة / سحب شامل من كل المصادر + **طابور المهام** بتقدم حي وإلغاء
3. **المصادر**: تفعيل/تعطيل، ترتيب أولوية، زمن استجابة (ms)، حالة (شغال/متدهور/متوقف)، فحص فوري، **فيلوفر تلقائي** (المصدر المتوقف يُتخطى)
4. **الإعلانات والوصول**: Banner/Interstitial/Rewarded (تفعيل + تردد + أكواد الشبكات) + حدود تحميل مجاني/فتح VIP — تُطبَّق فورًا بدون تحديث تطبيق
5. **بناء APK**: زر يبني APK موقّعًا من داخل اللوحة (1-3 دقائق) + سجل + رابط تحميل
6. التعليقات / المستخدمون / المحتوى المحجوب / مهام الجدولة / الفهرس المحلي

### محرك السحب الضخم
- **سحب 1000 عمل شامل** (شائع + حديث) بكل التفاصيل (غلاف/وصف/تقييم AniList/كل الفصول) عبر الطابور مع تقدم مئوي
- مزامنة يومية 100 عمل + تتبع الفصول كل 30 دقيقة (مثبت: أول تشغيل جلب 75 عملًا بصفر أخطاء)

### خادم الصور الوسيط
- `/img/*` يخزن الصور على القرص (X-Cache: MISS→HIT) مع Cache-Control أسبوعي + حظر المضيفات غير المسموحة + تنظيف تلقائي للقديم

### النشر
- **الرابط العام الحالي**: https://ban-courier-rated-entrepreneurs.trycloudflare.com
- **نشر دائم**: `render.yaml` (نشر بنقرة على Render مع قرص بيانات) + `Dockerfile` جاهزان في الجذر

## 6) تحديثات شاملة: الصور والفصول + الحساب والمظهر + البحث + APK

### إصلاحات الصور والفصول
- **أغلفة موحدة**: نسبة 2:3 ثابتة + object-fit: cover (ويب وأندرويد) — لا تشوه بعد الآن
- **صور الفصول عبر الوكيل**: القارئ يمرر كل الصور عبر `/img/` (كاش قرص + تجاوز حظر الـ Referer) — مثبت MISS→HIT
- **ترتيب الفصول الذكي**: فرز طبيعي (1، 1.5، 2، 10) + زر تبديل "الأقدم→الأحدث / الأحدث→الأقدم" في صفحة العمل وقائمة القارئ

### حساب المستخدم والمظهر
- **الملف الشخصي** (`#/profile`): رفع صورة شخصية (آمنة حجمًا ونوعًا)، تغيير الاسم وكلمة المرور (تحقق من القديمة)
- **المظهر العام**: فاتح ☀ / داكن 🌙 / **AMOLED أسود** ⬛ (أسود نقي للشاشات OLED)
- **فلاتر القارئ**: أصلي ◐ / أبيض وأسود ⬛ / ورقي-سيبيا 🟤 — في الويب (CSS) وأندرويد (ColorMatrix)

### الرئيسية والبحث
- **الرئيسية الجديدة**: سلايدر متحرك للأعمال الرائجة (5 ثوانٍ تلقائيًا) + تبويبات أنواع (مانجا/مانهوا/مانها) + **أحدث الفصول المضافة** (من الفهرس المحلي) + **شريط أكمل القراءة**
- **البحث المتقدم**: فلاتر الحالة (مستمر/منتهي/متوقف/ملغى)، النوع، المصدر، أدنى تقييم، والترتيب — عبر الفهرس المحلي مع سقوط تلقائي للبحث الحي
- **اقرأ الآن**: زر يفتح أول فصل غير مقروء مباشرة (يلي آخر تقدم محفوظ)

### البناء والرابط
- **رابط ثابت لأحدث APK**: `/builds/latest.apk` (يعيد أحدث ملف) + `/api/update/latest`
- **فاحص تحديثات داخل التطبيق**: أندرويد يقارن versionCode عند الإقلاع ويعرض "تنزيل التحديث" إذا توفر إصدار أحدث
- **APK 0.3.0** (versionCode 3): إضافة الفلاتر + فاحص التحديثات + SERVER_URL قابلة للتغيير في `app/build.gradle.kts`

## 7) تصميم Manga Melo Style (الواجهات الجديدة)

### الويب
- **شريط علوي**: زر القائمة الجانبية ☰ + البحث 🔍 + التنبيهات 🔔 + تبديل اللغة
- **تبويبات رئيسية**: آخر التحديثات 🆕 / الأكثر مشاهدة 🔥 / التحميلات ⬇ (تبدل محتوى الرئيسية)
- **بطاقات الشبكة**: شارة NEW للأعمال الحديثة (أقل من 7 أيام) + تقييم ذهبي ★ (من الفهرس/AniList) + عدد الفصول
- **القائمة الجانبية (Drawer)**: بطاقة الحساب (صورة/اسم/ملف شخصي)، التنقل (رئيسية/بحث/أعمال جديدة/سجل)، قوائم المستخدم (مفضلة/أقرأها الآن/اقرأ لاحقًا/المقروءة/الإشعارات/التحميلات)، الإعدادات (وضع ليلي، أسئلة شائعة، سياسة الخصوصية، الشروط، الإعدادات)، روابط التواصل، وزر تحميل APK
- **قوائم جديدة**: سجل المشاهدات (#/history)، اقرأ لاحقًا (#/readlater) مع زر ⏳ في صفحة العمل، الإشعارات (#/notifications) تعرض فصول المتابعات الجديدة من الفهرس
- **صفحات ثابتة**: FAQ / الخصوصية / الشروط (#/faq #/privacy #/terms)

### أندرويد (0.4.0)
- **درج جانبي** (Manga Melo style): تنقل + مكتبة + رابط تحميل APK
- **شريط تبويبات**: آخر التحديثات / الأكثر مشاهدة / التحميلات
- **بطاقات مطوّرة**: شارة NEW + تقييم ذهبي ★ + عدد فصول — **مع إثراء التقييمات من السيرفر** (by-ids)
- فلاتر القارئ + فاحص التحديثات محفوظان

### إصلاح صور الأغلفة (0.5.0)
- **كل الصور تمر عبر وسيطنا الآن**: الأغلفة (covers) وصفحات الفصول — `coverUrl` و`pageUrl` تعيدان `/img/<encoded>` (ويب) أو `<SERVER_URL>/img/<encoded>` (أندرويد) — لا يعتمد العرض على وصول متصفح المستخدم لـ uploads.mangadex.org (حل حظر المزود/الإقليمي نهائيًا)
- إصلاح Content-Type للصور المخزنة (image/jpeg حسب الامتداد) — قديمًا كانت تُعرض كـ octet-stream
- الاختبار: الغلاف عبر الرابط العام → 200 image/jpeg (MISS ثم HIT)
